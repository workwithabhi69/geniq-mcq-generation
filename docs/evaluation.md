# Evaluation Framework & Metrics Specification

## 1. Automated Research Metrics

### 1.1 Answer Correctness & Matching Rate
$$\text{Answer Matching Rate} = \frac{\sum_{i=1}^{N} \mathbb{I}(\text{Norm}(\hat{a}_i) = \text{Norm}(a_i^*))}{N} \times 100$$
Where $\text{Norm}(\cdot)$ denotes lowercase normalization, punctuation removal, and whitespace trimming.

### 1.2 Semantic Question Similarity
Computed using sentence embeddings generated by `all-MiniLM-L6-v2`:
$$\text{Sim}(q_{gen}, q_{ref}) = \frac{\mathbf{e}_{gen} \cdot \mathbf{e}_{ref}}{\|\mathbf{e}_{gen}\| \|\mathbf{e}_{ref}\|}$$

### 1.3 Context Grounding Score
A composite metric evaluating:
1. Exact or near-verbatim presence of `source_evidence` in the source passage.
2. Token-level containment of question and correct answer key in the support text.
$$\text{Grounding Score} \in [0.0, 1.0]$$

### 1.4 Valid Output Schema Rate
$$\text{Valid Schema Rate} = \frac{\text{Successfully Parsed and Pydantic-Validated Items}}{\text{Total Generation Invocations}} \times 100$$

### 1.5 Generation Latency
$$\bar{L} = \frac{1}{K} \sum_{k=1}^{K} t_{k} \quad (\text{milliseconds})$$

## 2. Human Qualitative Evaluation Framework

Rated on a standard 1–5 Likert scale by independent reviewers:
1. **Relevance to Passage**: Does the question assess core factual content from the provided passage?
2. **Factual Correctness**: Is the designated answer key indisputably correct?
3. **Question Stem Clarity**: Is the question unambiguously phrased without confusing double negatives?
4. **Distractor Plausibility**: Are the three incorrect options scientifically plausible and free of giveaway clues?
5. **Answer Uniqueness**: Is there exactly one correct answer among the 4 choices?
6. **Difficulty Calibration**: Does the question match the designated cognitive level (Easy, Medium, Hard)?

### Inter-Rater Reliability: Cohen's Kappa ($\kappa$)
$$\kappa = \frac{p_o - p_e}{1 - p_e}$$
Where $p_o$ represents observed agreement and $p_e$ represents hypothetical chance agreement.
